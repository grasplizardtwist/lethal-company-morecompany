# MoreCompany

### Increase the player count in Lethal Company

MoreCompany lifts Lethal Company's 4-player lobby cap, letting you play with up to 32 friends simultaneously. The more the merrier — and the more chaotic — when hunting for scrap on abandoned moons.

<br>

---

## Features

| | |
|:---|:---|
| **Up to 32 Players** | Expand lobbies from 4 to 32 players for massive co-op sessions |
| **Custom Cosmetics** | Community cosmetic system with hats and accessories for characters |
| **Stable Netcode** | Optimized network handling to keep large lobbies performing smoothly |
| **Wide Compatibility** | Works with most other popular Lethal Company mods |
